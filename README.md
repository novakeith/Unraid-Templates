# KNova's Unraid Templates

## NextSound-Unraid
Template for hosting Nextsound easily via the Unraid interface

If you prefer, here is how you can install this manually in Unraid:
1. Download the Unraid-Nextsound.xml template
2. copy it to ```/boot/config/plugins/dockerMan/templates-user/my-nextsound.xml``` within your Unraid installation (note the name change)
3. It will appear in the "Add Container" menu in the "Docker" management page, as a "User template"
